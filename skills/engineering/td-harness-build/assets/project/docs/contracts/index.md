## 1. 说明核对

站在调用者视角核对用途、调用方式、返回与错误处理。新增或修改接口时，核对字段含义、单位 / 格式、取值约束、必填条件、缺省 / 空值语义及必要的跨字段关系；说明由真实契约注释维护，并与实现核对。发现缺口报告位置与依据，文档维护不自动授权修改契约。

响应包装、状态码、错误结构及 Trace ID 传递按项目现状记录，不因整理文档改写接口或强加字段。无依据的约定标待确认，规范初始值不能当作运行事实。
