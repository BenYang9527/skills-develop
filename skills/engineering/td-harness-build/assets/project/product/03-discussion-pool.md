# Discussion Pool · 讨论池

保存本轮暂不实施、留待后续承接的讨论材料；[Backlog](02-backlog.md) 负责索引与安排，[PRD](01-prd.md) 保存已确认的产品要求。

移入、承接和清理按 [clarify.md §2.2](../docs/clarify.md#22-讨论如何流转) 执行。只读当前事项相关条目，不默认全量读取；迁入某轮 Discussion 不代表已获实施批准。

## 1. 讨论条目

没有待承接内容时留空。每个议题用与 Backlog 一致的稳定编号和短标题建立小节，记录：

- **背景与目标**：要解决的问题及必要上下文。
- **已明确的内容**：已讨论清楚的点、条件与理由；已成为正式要求的内容引用 PRD，不重复定义。
- **备选与取舍**：后续继续判断所需的方案及利弊。
- **未决问题**：尚待澄清、验证或确认的内容，不把猜测写成结论。
- **来源**：原讨论的定位，供获准时追溯；本条必须足以继续讨论，不能依赖读取旧任务正文。

## 2. 外部维护位置

用户指定后填写；沿用外部格式，按澄清规则维护对应内容。
