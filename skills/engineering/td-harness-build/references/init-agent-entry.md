# AGENTS 生成与审查

> **使用边界**：仅供初始化／升级。先读 [派发约定](init-agents.md#2-派发约定) 与 [共同生成方法](init-project-docs.md)，按主 Agent 指定的输入、文件范围和授权处理。

> 生成或融合项目 AGENTS 时读取。模板为 `assets/agents.md`，初始化／升级的修改边界见 [upgrade-project.md](upgrade-project.md)。

## 1. 保留结构与规则

本节用于生成、融合及应用入口候选。

### 1.1 生成候选

先完整读取原入口，识别 Workflow 中需要保留的项目独有规则。按 [升级规则](upgrade-project.md) 在隔离目录生成候选，原项目保持不动。

**build_harness.sh 对入口的处理：**

| 入口状态 | 脚本行为 |
|---|---|
| 不存在 | 复制 assets/agents.md 模板 |
| 已存在，章节边界明确 | 更新第二章 Workflow，保留其余章节 |
| 章节边界不明确，或入口为软链 | 保留原文并提示 **[MERGE]**；用 cp 复制模板到候选位置，再融合项目内容 |

在**尚未融合项目定制**的隔离目标生成候选，并验证重复生成的稳定性。融合后，不再运行构建脚本覆盖候选或原目标。

### 1.2 融合项目内容

**Workflow 保留模板原文，不概括重写。** 项目事实写入 Index、Commands、Structure、Rules。

原 Workflow 中的项目独有规则转入 **Rules**，已批准的流程差异也在这里集中说明。未解决的流程冲突交用户决定，解决后再应用。

### 1.3 核对并应用

用 **diff -u** 分别比较“模板与候选”“原入口与候选”，逐项核对新增事实、保留规则和已批准差异，再按授权应用。

退出码 **1** 表示存在差异，**大于 1** 才表示比较出错。只有只读权限时，返回候选，由主 Agent 应用。

## 2. 按证据填充

AGENTS.md 负责项目规则、稳定约束和跨任务导航，不承载具体任务链接、当前进度、审批结论、修复经过或验证结果。

| 位置 | 内容与依据 |
|---|---|
| 顶部项目 / Stack | 一句话用途及主要语言、框架；读取 README、已有入口及依赖配置 |
| Commands | 模块或包名、启动入口及构建、测试、生成命令；引用详细规范，缺失明确标记 |
| Structure | 关键目录职责、分层方向、生成代码边界；读取目录和调用关系 |
| Rules | 保留项目命名、数据访问、契约、迁移、注释、错误处理及保护分支等适用约束 |
| 主题索引 | 按下方必做步骤核对主题、实际文件和读取时机 |

仓库类型仅在影响操作时写入 Structure，例如多项目目录与工作目录。AI 有特殊职责时写入 Rules；“高级开发工程师”等通用角色不写。详细版本维护在项目配置和环境规范，必要的版本约束保留在 Rules。

模板骨架必须保留，必填事实未知时标明待定或不涉及，不编造内容。可选信息无实际作用时省略。项目语言不限于 Go；按真实技术栈采集。

### 主题索引填充

按 [04 Docs §3.2](../assets/workflows/development/04-docs.md#32-索引与引用) 核对索引方法，将模板路径替换为项目实际入口。使用 **rg --files --hidden** 定位文档、契约和工具配置，保留有效项目入口。实际路径核对完成前，不能把模板复制报告为索引接入完成。

## 3. 核对

- 对照旧入口逐条核对项目规则，独有内容已合并或列明冲突；不能以模板缺项为由丢弃。
- 实现授权、任务隔离、测试先行、真实证据及 Git 边界完整。
- 产品和开发的 Clarify 分工、AC 来源、AT 设计及执行位置一致。
- 主题索引逐项核对完成，实际契约、项目配置和专属规范入口已补齐；具体任务链接已排除，缺口明确报告。
- 文件及章节引用可达，尤其是阶段模板引用的 **AGENTS.md §2.6**、**Plan §6.1–6.4**；CI 或 hook 强制执行须有实际配置证明。
- Agent 分工入口指向 **.harness/agent-roles.md**，本阶段核对链接与职责位置；独立 Reviewer 配置和实际调用由后续 **agent-setup.md** 接入，未核验前不能写“已安装”。
- 核对 **§2.1** 的角色入口及 **agent-roles.md §1** 的实际定义；保留 **§2.3.4「反馈与返工」** 的阶段返回位置，交接与角色权限引用 agent-roles.md，不在入口复制定义。
- 主入口保持简短；详细说明通过专题引用提供，职责和硬约束不得为凑行数而删除。

交付前在隔离目录按候选入口创建一次开发任务：核对 **00–06** 文件齐全、章节与表格保留、后续阶段未标完成；已有目录重试不能覆盖内容。报告实际结果与差异，再由主 Agent 核对接入是否完成。
