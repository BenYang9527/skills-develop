# 日志规范生成指导

> **使用边界**：仅供初始化／升级。先读 [派发约定](init-agents.md#2-派发约定) 与 [共同生成方法](init-project-docs.md)，按主 Agent 指定的输入、文件范围和授权处理。

## 1. 调查与填写

从实际依赖、日志调用、初始化配置及运行说明核对日志库、等级、格式、关联字段、采集入口和保留策略，按 [logging.md](../assets/project/docs/logging.md) 填写。动态调级、敏感数据保护、重复错误与参数归属遵循模板，不另设规则。

## 2. 融合与核对

已有重复说明先保留独有内容，按升级授权融合、处理旧段落并修复引用；release.md 引用日志规范。核对实际配置与说明一致，报告核验范围及缺口。
