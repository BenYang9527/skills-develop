# 数据库文档生成指导

> **使用边界**：仅供初始化／升级。先读 [派发约定](init-agents.md#2-派发约定) 与 [共同生成方法](init-project-docs.md)，按主 Agent 指定的输入、文件范围和授权处理。

## 1. 调查与填写

先按 [能力探测](init-agent-detect.md) 核对持久化证据。识别项目使用的 Migration、Schema 或 ORM 定义及生成关系，读取相关配置与已有说明；无数据库时跳过生成，保留已有人工内容和历史。

按 [database.md](../assets/project/docs/data/database.md) 填用途、实体入口、关系、事务、迁移与项目约束。结构来源、快照、权限及运行事实边界均由该模板维护；无生成工具时保留源文件链接，不另建同步脚本。

## 2. 升级核对

核对说明及链接与结构来源一致。旧模板边界上方也可能有项目事实，完整读取后按升级授权融合。保留人工解释及历史脚本；重复定义和旧入口按升级规则处理。
