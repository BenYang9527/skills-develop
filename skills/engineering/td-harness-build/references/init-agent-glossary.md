# 术语表生成指导

> **使用边界**：仅供初始化／升级。先读 [派发约定](init-agents.md#2-派发约定) 与 [共同生成方法](init-project-docs.md)，按主 Agent 指定的输入、文件范围和授权处理。

## 1. 调查与填写

读取相关需求、已有术语说明、关键类型与标识符、配置和契约注释，识别影响理解的概念、缩写和歧义。收录标准、定义、别名与更名历史按 [glossary.md](../assets/project/docs/glossary.md)，不按搜索命中数决定收录或批量搬运行业术语。

## 2. 生成核对

每个 Harness 必须生成并保留术语表。按升级规则融合既有定义及历史；核对一词多义、同义词混用、缩写全称及代码用法，检查来源入口。缺口与冲突如实返回。
