# 失败记录生成指导

> **使用边界**：仅供初始化／升级。先读 [派发约定](init-agents.md#2-派发约定) 与 [共同生成方法](init-project-docs.md)，按主 Agent 指定的输入、文件范围和授权处理。

## 1. 定位与核对

初始化时从主 Agent 明确授权的项目历史中定位候选问题。读取、核实、复盘、验证和记录规则统一遵循 [failures.md](../assets/project/docs/failures.md)，不扩大历史读取范围。

## 2. 填写与报告

有符合收录标准的事件才填入项目区，按模板保留已有记录与归档；无事件不填示例事故。返回证据入口、实际核验状态与缺口，写入成功不能替代改进效果证据。
