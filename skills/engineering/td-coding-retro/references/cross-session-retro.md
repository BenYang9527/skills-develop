# 跨会话复盘

1. **按指定范围取证。** 只查用户指定的会话，或指定项目在指定时间段内的记录。范围不明确时，只补问缺失的信息。先读已有复盘、缺陷、失败和回滚记录，发现可能的共因后，再核对授权范围内必要的原始证据。说明实际覆盖范围和影响判断的材料缺口。
2. **按事件去重并核对共因。** 同一个 Bug、回滚或返工即使出现在多个会话或报告里，也只算一件事。只有多个独立事件的证据指向同一个失效机制，才列为共因；只看到相似表象或证据不足时，列为待核实线索。
3. **给出有依据的预防建议。** 默认直接汇报，每个共因列出支持它的独立事件、可追溯的来源，以及最值得尝试的预防或验证动作。判断是否值得沉淀时，沿用 [分类与沉淀](../SKILL.md#分类与沉淀)。如果没有足够证据支持共因，就说明缺什么证据。只提出建议，项目规则、自动化或 Skill 的修改另按用户授权处理。
