# 指标口径与报告数据

## 时间

- **总跨度**：明确起止事件之差，旁注事件及范围。Git 提交时间是事件，不是命令退出时间。中途睡觉不改变跨度。
- **可观察执行时间**：有起止证据的实际活动区间并集，主控、子 Agent 和工具重叠只计一次。另报覆盖范围；缺少活动边界时为未知。用户睡觉期间 Agent 仍可能工作。
- **阶段窗口合计**：阶段记录中有效起止窗口的并集；可能包含等待，不能称为实际工作时间。分别展示 01 澄清 Clarify、02 计划 Plan、03 实现 Implement、04 验证 Verify、05 文档 Docs、06 审查 Review、07 提交 Submit；00 Overview 不算阶段。
- 有返工时保留首轮与返工，计算各阶段内部并集；跨阶段重叠时，全局合计再取并集，不能直接相加。只有边界完整且范围一致时才报“七阶段完整合计”。
- 显式等待按证据标注；没有事件的空档保持未知。CLI 自报 duration 与消息首末时间分别保留原义，不能直接替代活动并集。只缺一个边界也不能按零计算。

## Implement 并行

对照 Plan 工作块与实际业务改动归属，区分业务实现和协议调查、测试设计、审查等辅助工作。模型替换、角色交接和多个会话不能单独证明并行；确认同时执行需活动区间证据。没有可比串行基线时，不报告净节省时间或提速倍数。

## 用量与费用

每组数据保留角色、模型、会话／计费段、时间范围和来源，先核实当前日志格式的计数语义。累计快照在同一计费段取末值，增量记录按唯一事件去重求和；重置或恢复后的段边界不明时分开列，不能硬加。父级已包含子 Agent 时只计一次，账单和日志覆盖同一调用也只计一次。

区分缓存输入、非缓存输入、输出；reasoning 等子集不能再次相加。缓存读写是否已包含在 input 中，以实际格式为准。不能确认分解时展示原字段，合计未知。只覆盖部分记录就注明部分，不冒充全任务。

实付账单与价格估算分开，保留币种、价格依据和覆盖范围。不同币种不直接相加；未知价格或不完整覆盖时，总成本未知。Token 数量、缓存命中率与生产率分别判断。

## 数据契约

渲染器只读已核对的 JSON。数值可为 **null**，表示未知；已知为零填写 0。所有展示字段都是纯文本，不支持 HTML。字段如下：

```json
{
  "title": "任务名 · 效率一览",
  "scope": "本次交付的边界",
  "outcome": "交付结果及尚未通过的验收边界",
  "times": [
    {"label": "总跨度", "seconds": null, "note": "起止事件与范围"},
    {"label": "可观察执行时间", "seconds": null, "note": "活动区间覆盖情况"},
    {"label": "阶段窗口合计", "seconds": null, "note": "完整性及等待边界"}
  ],
  "phases": [
    {"number": "01", "seconds": null, "note": "起止记录缺失"},
    {"number": "02", "seconds": null, "note": ""},
    {"number": "03", "seconds": null, "note": "首轮／返工口径"},
    {"number": "04", "seconds": null, "note": ""},
    {"number": "05", "seconds": null, "note": ""},
    {"number": "06", "seconds": null, "note": ""},
    {"number": "07", "seconds": null, "note": ""}
  ],
  "parallel": ["计划工作块、实际业务实现及辅助工作的比较"],
  "usage": ["按角色／模型的用量、覆盖范围和缓存口径", "账单实付与估算分别列示"],
  "bottlenecks": ["已知阻塞、返工及证据边界"],
  "bad_taste": [],
  "unknowns": ["影响判断的数据缺口"],
  "sources": [{"id": "E1", "path": "实际证据路径", "locator": "行号、事件 ID 或字段", "supports": "支持的数字或判断"}]
}
```

**times** 固定为上面三项；**phases** 按顺序完整保留七项，使用相同时间范围。其他列表允许为空；Bad taste 每项可写成“观察；影响；建议 [E1]”。正文数字和重要判断用 **[E1]** 等编号指向 sources。SVG 展示证据编号与简短说明，完整路径在 JSON，避免把日志细节铺满画布。

底稿可在上述字段之外保存去重过程、时间区间和计算式供核查，渲染器忽略额外字段。总量由分析者核对，渲染器不把各阶段数字自动相加。
